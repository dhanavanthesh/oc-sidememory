# Provenance

OC-Sidememory began from the Apache-2.0 outlines-core source tree at commit `116a7c381b446814fdfc9b2b28bea7ca4f900aae`.

Later commits add the checked compiler, exact canonical values, cursor, semantic router, transactional guide, semantic constraints, rollback, and public integrations. OC-Sidememory is independent and is not endorsed by outlines-core.
